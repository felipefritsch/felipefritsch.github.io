# Felipe Fritsch — Research & Learning

Personal website: https://felipefritsch.github.io

Research, CV, Columbia honors thesis, Oxford dissertation links, public code and a reading-first learning wiki.

## Edit and publish

- Homepage: `docs/index.html`
- Design: `docs/style.css`
- Wiki master: `docs/wiki/Study_Wiki.md`
- Regenerate the wiki: `node scripts/build-wiki.cjs`
- Check links: `python3 scripts/check-site.py`

GitHub Pages publishes `main` / `docs`. Changes pushed to that branch are published automatically. The public wiki omits private notes and third-party textbook PDFs.
